# Decisions

- Use LangGraph for agent control/checkpoints and a Protocol-based SQLite store for durable versioned evidence. Filesystem state is restored separately through git worktrees: graph state alone is not an environment checkpoint.
- Use a strict JSON tool protocol, Pydantic validation and httpx async HTTP transport. Global in-process semaphore <=8, bounded output/context; do not exploit 1M context at concurrent capacity.
- Start with dependency-free Python MicroRepos and an external deterministic verifier. Keep tests outside editable files, disallow unrestricted shell and run only allowlisted tools. Isolation strength will be documented and checked before executing model-written code.
- Evidence is generated by execution only. Failed or unexecuted proposals cannot be promoted by model declarations.

- Native AsyncSqliteSaver records graph checkpoints; each graph snapshot also records an exact post-action git commit and tree hash. Resume copies the checkpoint database, branches a fresh worktree and verifies the tree hash before running the pending graph node. Original source files and graph history are preserved.
